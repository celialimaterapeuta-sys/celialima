COMO APLICAR:

1. Backup da pasta do projeto local.

2. Extrai o zip DENTRO da pasta do projeto (a que tem package.json).
   Substituir SIM quando perguntar.

3. No terminal, dentro da pasta do projeto:

   git add .
   git commit -m "feat: paleta lilás+dourado + céu estrelado (sem lua) + imagens editoriais"
   git push origin main

4. A Vercel detecta e faz deploy automático.
   Acompanhe em: https://vercel.com/dashboard

5. Quando Ready, acesse: https://www.celialima.com.br
